ZONTES 150X — Netlify Edition v2.0 (ไม่ใช้ Google Sheet / Apps Script แล้ว)
=====================================================================

เป้าหมายของเวอร์ชันนี้
- ทุกอย่างทำงานอยู่บน Netlify ที่เดียว ไม่ต้องพึ่ง Google Sheet หรือ Apps Script อีกต่อไป
- ข้อมูลรถ, ตารางเช็คระยะ, บันทึกนอกระยะ ฯลฯ เก็บอยู่ใน "Netlify Blobs"
  (ระบบเก็บข้อมูลแบบ Key-Value ที่มากับ Netlify โดยตรง ไม่ต้องตั้งฐานข้อมูลแยก)
- หน้าตา, ฟังก์ชันการใช้งาน, ตารางเช็คระยะ 0–100,000 กม., การคำนวณงบประมาณ/วันนัดหมาย,
  การเปิดแอปแล้วเห็นข้อมูลเดิมทันทีจาก Local Storage ก่อนซิงก์ของจริง — เหมือนเดิมทุกจุด
  ไม่มีการเปลี่ยนแปลงส่วนที่ผู้ใช้มองเห็นหรือใช้งานเลย

เปลี่ยนจากเวอร์ชัน Netlify+Google Sheet เดิมอย่างไร
-----------------------------------------------------
เดิม:  หน้าเว็บ (Netlify) → Netlify Function → Apps Script (Code.gs) → Google Sheet
ใหม่:  หน้าเว็บ (Netlify) → Netlify Function (api.mjs) → Netlify Blobs

- ไม่ต้องมี Code.gs, ไม่ต้องมี Apps Script Deployment, ไม่ต้องมี Google Sheet อีกต่อไป
- ไม่ต้องตั้งค่า GAS_WEBAPP_URL / GAS_API_TOKEN อีกต่อไป
- เหลือ Environment Variable ที่ต้องตั้งค่าเพียงตัวเดียวคือ APP_PIN (เหมือนเดิม)
- ตรรกะทั้งหมดที่เคยอยู่ใน Code.gs (ตรวจสอบเลขไมล์ห้ามย้อนกลับ, บันทึกข้อมูลรถได้ครั้งแรกครั้งเดียว,
  merge ประวัติเช็คระยะกับตารางมาตรฐาน ฯลฯ) ย้ายมาอยู่ใน netlify/functions/api.mjs ทั้งหมด
  ด้วยเงื่อนไขเดียวกันทุกจุด

⚠ ข้อมูลเก่าใน Google Sheet จะไม่ถูกย้ายมาให้อัตโนมัติ
เวอร์ชันนี้เริ่มต้นจากฐานข้อมูลว่างเปล่าใน Netlify Blobs
ถ้าต้องการนำประวัติเช็คระยะ/บันทึกนอกระยะเดิมจาก Google Sheet มาใส่ด้วย
ต้องกรอกใหม่ผ่านหน้าเว็บเอง หรือแจ้งให้ช่วยทำสคริปต์ย้ายข้อมูลครั้งเดียวเพิ่มเติมได้

ไฟล์ในชุดนี้
1. public/index.html              → หน้า WebApp (ไม่มีการแก้ไข UI/ฟังก์ชันจากเดิม)
2. netlify/functions/api.mjs      → Backend เดียว จบทุกอย่าง (ตรวจ PIN + อ่าน/เขียน Netlify Blobs)
3. netlify.toml
4. package.json                   → ระบุ dependency @netlify/blobs ให้ Netlify ติดตั้งตอน Build

(ไม่มี Code.gs และ gas-proxy.mjs อีกต่อไป เพราะไม่ได้ใช้ Google Sheet/Apps Script แล้ว)

ขั้นตอนติดตั้ง
---------------
1. Push โครงสร้างไฟล์ทั้งหมดนี้ขึ้น Git repository (GitHub/GitLab/Bitbucket)
   แนะนำให้ Deploy ผ่าน Git เพราะมี Netlify Functions และ Dependency ที่ต้อง npm install
   ไม่ใช่ Static Drag & Drop อย่างเดียว
2. สร้างไซต์ใหม่ใน Netlify แล้วเชื่อมกับ repository นี้
3. ไปที่ Site settings > Environment variables แล้วเพิ่ม:
   - APP_PIN = PIN ที่คุณกำหนดเอง เช่น 6–10 ตัวอักษร/ตัวเลข
4. Deploy
   Netlify จะรัน npm install (ติดตั้ง @netlify/blobs) แล้ว build/publish โฟลเดอร์ public
   พร้อมสร้าง Function จาก netlify/functions/api.mjs ให้อัตโนมัติ
5. เปิด URL ของไซต์ ครั้งแรกจะถามหา PIN ตามที่ตั้งไว้
   กรอกข้อมูลรถ (ชื่อเจ้าของ/ทะเบียน/วันที่เริ่มใช้) ครั้งแรกได้ตามปกติ

ทดสอบ
-------
- เปิด/ปิด WebApp หลายรอบ ควรเห็นข้อมูลเดิมจาก Cache ทันที แล้วซิงก์ของจริงตามมา
- อัปเดตเลขไมล์ / บันทึกรอบเช็คระยะ / บันทึกนอกระยะ / แก้ไข / ลบ
- ปิดเบราว์เซอร์แล้วเปิดใหม่ (หรือเปิดจากอุปกรณ์อื่น ใส่ PIN เดียวกัน) ควรเห็นข้อมูลที่บันทึกไว้ครบ

ดูหรือสำรองข้อมูลดิบ (แทนที่การเปิด Google Sheet แบบเดิม)
-----------------------------------------------------------
ไปที่ Netlify Dashboard > เลือกไซต์นี้ > แท็บ "Blobs"
จะเห็น Store ชื่อ "zontes150x" และ Key ชื่อ "app-data"
กด Download เพื่อดู/สำรองข้อมูลดิบเป็นไฟล์ JSON ได้ทุกเมื่อ โดยไม่ต้องเขียนโค้ดเพิ่ม

ความปลอดภัย
-------------
- APP_PIN ใช้ป้องกันคนอื่นที่เปิด URL แล้วแก้ข้อมูล ส่งผ่าน HTTPS เข้ารหัสอยู่แล้ว
  แต่ยังไม่มีการจำกัดจำนวนครั้งที่ลองผิด (Rate limit) ฝั่ง Function
  หากกังวลเรื่องการเดา PIN แนะนำตั้ง PIN ให้ยาวและไม่ใช่ตัวเลขล้วน
- ข้อมูลใน Netlify Blobs เข้ารหัสทั้งตอนจัดเก็บและระหว่างส่ง และเข้าถึงได้เฉพาะผ่านไซต์นี้เท่านั้น
- publish = "public" ทำให้มีเฉพาะไฟล์ในโฟลเดอร์ public ที่ถูกเผยแพร่เป็นไฟล์สาธารณะ

ข้อจำกัดที่ควรทราบ
--------------------
- Netlify Blobs เป็น Key-Value เก็บทั้งข้อมูลแอปเป็นก้อนเดียว ไม่มีระบบ Lock ป้องกันการเขียนชนกัน
  (หลักการคือ "เขียนล่าสุดชนะ") สำหรับแอปที่ใช้คนเดียวหรือไม่กี่คนพร้อมกันแบบนี้ไม่มีผลกระทบในทางปฏิบัติ
  แต่ถ้าเปิด 2 อุปกรณ์พร้อมกันแล้วบันทึกพร้อมกันเป๊ะ ๆ ค่าที่บันทึกทีหลังจะทับของก่อนหน้า
- ยังไม่มีปุ่ม Export/Import ข้อมูลในตัวแอป ถ้าต้องการฟีเจอร์นี้เพิ่ม แจ้งได้

หมายเหตุด้านความเร็ว
----------------------
- HTML/CSS/JS เปิดจาก Netlify CDN จึงเร็วเหมือนเดิม
- การบันทึก/อ่านข้อมูลตอนนี้จบภายใน Netlify ทั้งหมด (Function → Blobs) ไม่ต้องออกไปเรียก Apps Script
  ภายนอกอีกต่อไป ดังนั้นเวลาบันทึกควรเร็วขึ้นกว่าที่ต้องผ่าน Google Sheet เดิม
